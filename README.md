# HR Analytics Dashboard | Power BI

## Project Overview
This project analyzes employee data using Power BI to understand workforce demographics, hiring trends, and work locations.

## Objectives
- Calculate total employees and average employee age.
- Compare Headquarters and remote employees.
- Analyze hiring trends by year.
- Visualize gender distribution.
- Analyze employees by state, department, and race.
- Provide insights and recommendations for HR decision-making.

## Tools Used
- Power BI Desktop
- MySQL
- Git and GitHub

## Dashboard Visualizations
- Hiring Trend by Year — Line Chart
- Gender Distribution — Donut Chart
- Employees by State — Bar Chart
- Employees by Department — Bar Chart
- Employees by Race — Bar Chart
- Employee KPI Cards

## Recommendations
- Monitor hiring trends for workforce planning.
- Review staffing levels across departments and states.
- Evaluate remote and Headquarters workforce distribution.
- Support fair and inclusive HR practices.

## How to View
Download the `.pbix` file from this repository and open it using Power BI Desktop. Configure an authorized data connection if required.
